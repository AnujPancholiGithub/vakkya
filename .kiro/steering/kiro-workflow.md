# Kiro Development Workflow for Vakkya

## Core Principle: Iterative Enhancement Over File Explosion

**NEVER create new files when asked for improvements.** Always enhance existing code.

## MCP Tools Available

You have access to these real-time information sources:
- **Perplexity MCP**: For latest documentation, API changes, best practices
- **Tavily MCP**: For technical research, error solutions, architecture patterns

**Use these tools when:**
- Encountering unfamiliar API errors
- Checking if a package version has breaking changes
- Researching production deployment patterns
- Finding security best practices

**DO NOT use these tools for:**
- Basic syntax questions (refer to tech.md)
- Already-defined architecture decisions (refer to product.md, tech.md)
- Questions answered in steering files

## Development Flow

### 1. Before Writing Code
Read relevant steering files → Check existing codebase → Plan minimal changes
