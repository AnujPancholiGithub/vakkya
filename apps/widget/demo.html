Vakkya Widget Demo

About This Demo

This page demonstrates the Vakkya voice widget integration. The widget appears as a floating button in the bottom-right corner.

Click the button to start a voice conversation with the AI assistant.

Integration Code

Add this single line to your website:

<script src="https://cdn.vakkya.ai/widget.js" data-token="your-token"></script>

Features

  • Real-time voice conversation
  • Context-aware responses from your documents
  • Works on mobile and desktop
  • Lightweight (<100KB gzipped)
